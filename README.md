# Aev0rnGen

ブラウザ内でパスワードを生成する、無料の静的Webサイトです。

## 公開サイト

GitHub Pages の設定後、サイトURLは通常次の形式になります。

https://mylifereading6666-oss.github.io/Aev0rnGen/

## 機能

- パスワード長を4〜128文字で設定
- 英大文字・英小文字・数字・記号の選択
- 記号セットのカスタマイズ
- 紛らわしい文字の除外
- 選択した各文字種類を最低1文字含める設定
- 生成履歴内の完全重複と、同じ長さの候補の類似を防止
- ワンクリックコピー
- ダークテーマ、青系アクセント、鍵・シールドのアイコン

## プライバシーとセキュリティ

- 乱数はブラウザの `crypto.getRandomValues()` で生成します。
- パスワード生成はブラウザ内で完結し、サーバーに送信しません。
- 履歴はページ内メモリのみで管理し、再読み込みやページ終了で消えます。
- 外部ライブラリ、アカウント、分析用トラッキング、バックエンドは使用しません。
- クリップボードAPIはブラウザによってHTTPS環境が必要です。

類似防止を有効にすると、過去のパスワードに似た候補が除外されるため、無条件の一様分布とは異なります。候補が見つからない場合はエラーを表示します。

## GitHub Pages の有効化

リポジトリの **Settings → Pages** を開き、**Build and deployment** の **Source** で **GitHub Actions** を選択してください。リポジトリにはデプロイ用ワークフローが含まれており、main ブランチへの push 後に公開処理を行います。公開完了後、上記のURLを開いてください。

サイト本体は `index.html` 一つで動作します。
